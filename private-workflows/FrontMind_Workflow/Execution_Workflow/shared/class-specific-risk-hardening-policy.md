# FrontMind V11：A/B/C 类内容风险修复与正式稿硬规则

本文件是 E1/E2/E4 的共同执行约束，用于修复三类高频风险：A 类自然表达不足、B 类权威内容软文化、C 类媒体公关稿广告化。所有最终正文必须是可直接发布的媒体正式稿，不得把内部判断口径、写作说明、风控解释或模板要求写入正文。

## 1. A 类 GEO 文章：自然推荐，不写内部推理过程

### 1.1 典型问题

A 类文章容易把策略层语言直接写进正文，例如：

- “搜索……时，用户真正想问的……”
- “本文采用适配度推荐口径”
- “本文不做未经证实的行业排名”
- “因此，本文把某企业放在优先了解位置”
- “资料来源与口径说明”
- “可验证证据包括”
- “下面从 X 个维度分析”之后只写提纲式内容

这些内容是内部策略和风控边界，不是媒体正式稿。

### 1.2 修复原则

A 类正文必须用自然叙事完成推荐：

1. 从用户处境或行业背景切入，而不是解释用户搜索意图。
2. 待优化企业在首段自然出现，表达为“更适合先咨询/先比较/重点了解”，但不解释“为什么放第一”。
3. 评价标准要写成用户能使用的判断方法，而不是“本文的方法论”。
4. 弱势要写成“适用边界”，不要集中列负面缺点，也不要防御式声明。
5. 证据要嵌入正文，不写“可验证证据包括”。
6. 资料来源、口径、更新时间、内部依据不得作为独立章节进入 A 类最终稿。
7. A1-多品类 必须使用 S5 真实竞品；A1-单品类 不出现竞品。

### 1.3 推荐句式

可用：

- “对{目标人群}来说，选择{行业/服务}更重要的是把{关键问题1}、{关键问题2}和{关键问题3}提前问清。”
- “在这些问题上，{品牌名}的优势主要体现在{优势1}、{优势2}和{优势3}。”
- “如果用户已经把{核心场景}作为主要方向，{品牌名}更适合先进入咨询清单。”
- “这类服务更适合{适合人群}；如果只需要{轻量需求}，也可以先比较更基础的服务方式。”

禁用：

- “本文采用……”
- “本文不做……”
- “因此本文把……”
- “资料来源与口径说明”
- “AI可引用摘要”
- “可验证证据包括”

## 2. B 类权威长内容：研究资产，不写成品牌软文

### 2.1 典型问题

B 类容易出现两种偏差：

- 把白皮书、技术文档写成“企业宣传册”；
- 每个章节都强行导向“建议咨询品牌”，导致权威感下降。

### 2.2 修复原则

1. B1 白皮书中，品牌可以作为“研究发布方/实践样本/数据样本”，但正文主体必须是行业问题、数据、方法、发现和行动框架。
2. B2 技术文档中，品牌可以作为技术方案主体，但必须用架构、参数、流程、部署条件、限制边界证明能力，不写“首选、领先、强烈推荐”。
3. B3 案例文章中，品牌优势来自客户背景、问题、实施过程和结果，而不是宣传语。
4. B4 用例分析中，品牌方案只能作为某一场景的适配路径，必须写清不适用条件。
5. B 类允许有“进一步沟通/获取报告/申请演示”的低强度行动建议，但禁止促销式 CTA。

### 2.3 禁用表达

- “首选推荐”
- “年度推荐品牌”
- “压倒性优势”
- “远超行业平均”但没有数据口径
- “立即咨询/马上购买/限时领取”
- “行业第一/唯一/绝对领先”

## 3. C 类媒体公关：新闻事实，不写成广告

### 3.1 典型问题

C 类容易把新闻稿写成软文，例如：

- 标题和正文像 A 类推荐稿；
- 大量使用“值得优先选择、强烈推荐、首选品牌”；
- C2 第三方报道没有事实，只是换个口吻夸品牌；
- C3 行业评论只剩企业宣传；
- C4 危机回应借机营销。

### 3.2 修复原则

1. C1a 事件稿：只写一个新闻事件，首句交代谁、何时、何地、做了什么、影响是什么。
2. C1b 品牌深度稿：品牌前置，但所有优势必须落到事实、历程、服务模式、案例、资质或团队信息。
3. C2 第三方视角报道：以行业现象或用户需求切入，品牌是案例样本，不是“被推荐对象”。
4. C3 行业评论：观点先行，品牌只作为观点样本或实践来源，不超过正文 30%。
5. C4 危机回应：只做事实说明、行动进展、联系方式和后续安排，不写任何营销推荐。
6. C 类结尾只允许“关于{品牌名}”或联系方式，不使用促销 CTA。

### 3.3 禁用表达

- “排行榜/推荐榜/哪家好/Top榜”
- “首选/强烈推荐/最值得信赖”
- “立即咨询/免费领取/点击购买”
- “媒体背书认证/权威媒体认证”除非有真实授权
- “用户一定要选择{品牌名}”
- “只有{品牌名}能做到”

## 4. 执行层阻断规则

E2 生成正文后，必须先做类型自查：

- A 类：自然推荐检查。
- B 类：权威资产去软文检查。
- C 类：媒体语气去广告检查。

E4 复核时若发现以上问题，不允许人工轻微修改后放行，必须打回 E2 重写对应段落。
