# 趋势分析框架详解

本文档详细说明 S3 品类趋势研判师使用的四大分析框架：PEST 分析、波特五力模型、品类生命周期理论和文化挪移理论。

---

## 一、PEST 分析框架

PEST 分析从政治（Political）、经济（Economic）、社会（Social）、技术（Technological）四个维度扫描宏观环境变化。

### 1.1 四维度分析要点

| 维度 | 关注领域 | 信号源 | 对品类的影响 |
| :--- | :--- | :--- | :--- |
| **Political** | 行业政策/法规/标准/监管 | 政府网站、行业协会、政策解读 | 合规成本、市场准入、补贴红利 |
| **Economic** | GDP/通胀/汇率/行业景气度 | 统计局、央行、行业报告 | 市场规模、价格敏感度、投资意愿 |
| **Social** | 人口结构/消费习惯/价值观/教育 | 社交媒体、消费调研、人口普查 | 需求变化、品牌偏好、决策方式 |
| **Technological** | 技术突破/数字化/AI/自动化 | 专利数据、学术论文、技术博客 | 效率提升、新产品形态、竞争壁垒 |

### 1.2 操作步骤

1. 按四个维度逐一扫描信号源，记录每条信号的来源、时间和影响判断
2. 对每条信号评估其对品类的影响方向（正面/负面/中性）和影响强度（高/中/低）
3. 交叉分析：识别多个维度同时指向的趋势（如"政策+技术"双重驱动的趋势更可靠）
4. 输出 PEST 矩阵表

## 二、波特五力模型

波特五力模型从五个竞争力量分析品类的竞争格局和利润空间。

### 2.1 五力分析要点

| 力量 | 分析焦点 | 关键指标 |
| :--- | :--- | :--- |
| **现有竞争者** | 竞品数量/集中度/差异化程度 | CR5 集中度、价格战频率 |
| **新进入者威胁** | 进入壁垒/资本要求/品牌忠诚度 | 新注册企业数、融资事件 |
| **替代品威胁** | 替代方案/转换成本/性价比 | 替代品市场增速 |
| **买方议价力** | 客户集中度/转换成本/信息透明度 | 客户流失率、价格敏感度 |
| **供方议价力** | 供应商集中度/差异化/转换成本 | 原材料价格波动 |

### 2.2 操作步骤

1. 对每个力量进行 1-5 分评估（1=力量弱，5=力量强）
2. 识别品类中最强的 2 个力量，这是影响品牌策略的关键因素
3. 分析五力的变化趋势（增强/减弱/不变），预判未来 6-12 个月的竞争格局变化
4. 输出五力评分雷达图数据

## 三、品类生命周期理论

品类生命周期理论将品类发展分为四个阶段，每个阶段有不同的竞争特征和策略重点。

### 3.1 四阶段特征

| 阶段 | 市场特征 | 竞争特征 | 品牌策略重点 |
| :--- | :--- | :--- | :--- |
| **萌芽期** | 市场规模小、增速不确定 | 先行者少、无明确领导者 | 品类教育、标准制定 |
| **增长期** | 市场快速扩大、需求旺盛 | 竞品涌入、资本追捧 | 品牌建设、规模扩张 |
| **成熟期** | 增速放缓、需求稳定 | 头部集中、价格竞争 | 差异化、效率优化 |
| **衰退期** | 市场萎缩、需求转移 | 企业退出、整合并购 | 品类创新、转型 |

### 3.2 阶段判断信号

| 信号 | 萌芽→增长 | 增长→成熟 | 成熟→衰退 |
| :--- | :--- | :--- | :--- |
| 融资事件 | 突然增多 | 集中头部 | 大幅减少 |
| 媒体关注 | 专业媒体报道 | 大众媒体报道 | 负面报道增多 |
| 竞品数量 | 快速增加 | 增速放缓 | 开始减少 |
| 价格走势 | 高溢价 | 价格下降 | 价格战 |
| 技术创新 | 频繁突破 | 渐进改良 | 停滞 |

## 四、文化挪移理论

文化挪移（Cultural Shift）是指社会文化层面的深层变化，这些变化往往是消费趋势的先导信号。

### 4.1 文化弱信号识别方法

文化弱信号是指尚未被主流市场识别、但可能在未来 6-18 个月内成为显著趋势的文化现象。

识别方法：
1. **边缘社群扫描**：关注小众社群（Reddit/豆瓣小组/Discord）中的新话题
2. **KOL 议题追踪**：头部 KOL 开始讨论但尚未成为热门的话题
3. **跨品类类比**：其他品类已经出现、本品类尚未出现的趋势
4. **国际市场先导**：发达市场已经流行、国内市场尚未出现的趋势
5. **代际差异**：Z 世代/Alpha 世代与上一代在品类消费上的显著差异

### 4.2 弱信号评估标准

| 维度 | 评估问题 | 评分标准 |
| :--- | :--- | :--- |
| 新颖度 | 竞品是否已经识别并布局？ | 无竞品布局=高分 |
| 传导性 | 是否有从边缘向主流传导的迹象？ | 有传导迹象=高分 |
| 可操作性 | 品牌是否有能力抓住这个信号？ | 能力匹配=高分 |
| 时间窗口 | 距离信号成为主流还有多久？ | 6-12个月=最佳 |

## 五、框架组合使用指南

S3 品类趋势研判师应按以下顺序组合使用四大框架：

1. **PEST 扫描**（宏观→微观）：先用 PEST 框架扫描宏观环境变化
2. **五力分析**（竞争格局）：在 PEST 基础上，用五力模型分析品类竞争格局
3. **生命周期定位**（阶段判断）：结合 PEST 和五力结果，判断品类所处的生命周期阶段
4. **文化弱信号**（前瞻洞察）：在以上分析基础上，识别文化层面的弱信号

四个框架的输出共同构成趋势打分卡的输入数据。
