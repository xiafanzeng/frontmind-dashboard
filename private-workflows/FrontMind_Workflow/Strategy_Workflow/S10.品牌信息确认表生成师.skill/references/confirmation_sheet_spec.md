# S10 品牌信息确认表 — 双子表规范

本规范定义 S10 输出的《{brand}_品牌信息确认表.xlsx》两个子表的列结构、数据来源与配色，供 `brand_info_confirmation_generator.py` 与人工复核使用。

## 一、配色（取自《品牌信息收集表》精确色值）

| 元素 | HEX | 说明 |
| :--- | :--- | :--- |
| 主标题 / 区段标题栏 | `#4A154B` | 深紫底，白字 |
| 副标题字 | `#D1C4E9` | 浅紫 |
| 表头行 | `#6B3FA0` | 中紫底，白字 10pt 加粗 |
| 数据行（奇） | `#FFFFFF` | 白 |
| 数据行（偶） | `#F9F7FC` | 极浅紫 |
| **企业填写列** | `#FFFDE7` | 浅黄底 + `#4A154B` 紫字（必须高亮） |
| `[必填]` | `#D32F2F` | 红字 |

| 预填内容字 | `#424242` | 深灰 |
| 备注字 | `#757575` | 浅灰 |

## 二、子表1「品牌信息确认」

六列：`# | 条目名称 | 填写要求 | 已有内容（预填）| ✏️ 企业填写 / 修改 | 备注说明`

子表1 **完整复刻《品牌信息收集表》的全部 13 个品牌信息区段**，逐条结构维护在 `brand_info_confirmation_generator.py` 的 `SHEET1_SECTIONS` 常量中：

| # | 区段 | 条目概要 | fill 模式预填来源 |
| :--- | :--- | :--- | :--- |
| 一 | 品牌基础信息 | 企业全称 / 品牌简称 / 所属行业 / 企业官网 / 联系方式 | S1 |
| 二 | 品牌定位与价值主张 | 一句话定位 / 核心价值主张 / 差异化优势 | S4 |
| 三 | 产品 / 服务矩阵 | 主营产品线 1-4 / 配件耗材 / 其他 / 重点推广方向 | S1/S2 |
| 四 | 核心优势 | 产品覆盖 / 服务链 / 配件长尾 / 多平台触达 / 中小客户适配 / 证据透明化 | S4/S1 |
| 五 | 目标客群 | 客户类型 / 行业人群 / 规模分布 / 地域分布 | S2 |
| 六 | 资质认证 | ISO / CE·SGS / 证书编号有效期 / 专利软著 | S1 |
| 七 | 客户案例 | 案例 1-2（客户/痛点/方案/成果）/ 更多案例 | S1/S7 |
| 八 | 量化经营数据 | 成立年份 / 员工 / 营收 / 产能 / 客户数 / 服务年限 / 装机量 / 转化复购率 / 合作伙伴数 | S1 |
| 九 | 竞争格局 | 主要竞品 1-3 / 更多竞品 / 客户决策因素排序 | S3/S5 |
| 十 | 服务区域 | 总部核心区域 / 重点覆盖区域 / 全国·海外覆盖 | S1 |
| 十一 | 品牌历史与里程碑 | 创立背景 / 关键里程碑 / 未来愿景 | S1 |
| 十二 | 备注与想法 | 营销痛点 / 品牌形象调性 / 客群判断 / 近期计划 / 竞品观察 / 其他 | S6 + 企业 |
| 十三 | 补充材料清单 | BP / 产品手册 / 官网 / 客户评价 / 行业报告 / 团队资料 / 其他 | 企业提供 |

> **重要**：删除原《品牌信息收集表》末尾的「提出的问题」与「AI 可见性监测准备」区段（后者归入子表2）。template 模式下预填列统一为「（由策略层 S1-S9 自动填充）」占位，不写任何企业信息。

## 三、子表2「监控问题与应答逻辑确认」

**五列**：`# | 监控问题 | 应答逻辑（预填）| ✏️ 企业想修改 | 参考资料`（**已删除「应答逻辑备注」列**）

| 列 | 数据来源 |
| :--- | :--- |
| 监控问题 | 企业已填写《应答逻辑确认表》第 1 列（区段标题原样保留） |
| 应答逻辑（预填） | 应答逻辑确认表第 2 列 |
| ✏️ 企业想修改 | 留空高亮列，供企业填写调整意见 |
| 参考资料 | 应答逻辑确认表第 4 列（原第 3 列「应答逻辑备注」不再读取） |

> fill 模式下子表2 必有内容（因为输入就是企业已填写的应答逻辑确认表）。若解析为 0 条，必须阻断并向用户索取正确的应答逻辑确认表。template 模式则输出若干空白示意行。

## 四、列宽建议

- 子表1：A=5, B=24, C=10, D=52, E=52, F=44
- 子表2：A=5, B=38, C=58, D=38, E=30
