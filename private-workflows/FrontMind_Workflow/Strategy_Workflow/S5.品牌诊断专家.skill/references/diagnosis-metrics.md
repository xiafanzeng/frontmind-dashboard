# 7 维诊断指标体系详解

本文档详细定义 S5 品牌诊断专家使用的 7 维诊断指标体系，包括每个维度的定义、计算公式、评分标准和数据来源。

---

## 一、指标体系总览

| 维度 | 编号 | 权重 | 定义 | 评分范围 |
| :--- | :--- | :--- | :--- | :--- |
| AI 可见度 | D1 | 20% | 品牌在 AI 回答中被提及的频率和位置 | 0-100 |
| 语义准确度 | D2 | 15% | AI 描述的品牌信息与事实图谱的一致性 | 0-100 |
| E-E-A-T 信号 | D3 | 15% | AI 回答中体现的经验/专业/权威/可信度 | 0-100 |
| 竞品对比 | D4 | 15% | 品牌与竞品在 AI 回答中的相对位置 | 0-100 |
| 用户意图覆盖 | D5 | 10% | AI 回答覆盖用户意图的完整度 | 0-100 |
| 负面舆情 | D6 | 10% | AI 回答中负面信息的出现频率和严重度 | 0-100 |
| 定位 Gap | D7 | 15% | AI 实际呈现与理想定位的偏差程度 | 0-100 |

综合分 = Σ(维度分 × 权重)

---

## 二、D1 AI 可见度（Visibility）

### 2.1 定义

衡量品牌在 AI 搜索回答中被"看见"的程度，包括是否被提及以及提及的位置。D1 只适用于泛品类推荐、供应商推荐、品牌对比、方案选择等存在自然竞争与排名意义的问题；直接点名品牌的缺点、问题、投诉、口碑、风险、负面评价类舆情类问题不参与 D1 可见度，必须从 D1 中排除，因为品牌出现由题干指定，不能解释为可见度优势。

### 2.2 计算公式

```
引用率 = 可排名样本中品牌被提及的回答数 / 可排名样本总回答数 × 100

位次得分 = Σ(单条位次得分) / 被提及回答数
  其中：位次 1 = 100分, 位次 2 = 80分, 位次 3 = 60分, 位次 4 = 40分, 位次 5+ = 20分

D1 = 引用率 × 0.6 + 位次得分 × 0.4
```

### 2.2.1 S5→S5.5 位次诊断补充口径

D1 的位次得分只回答“可见度评分”问题，但 S5 还必须生成可被 S5.5 复用的 `ranking_position_diagnostics`。该对象不改变 7 维评分权重，而是把 `avg_rank`、`first_place_rate`、`top3_rate`、`top5_rate`、`rank_distribution`、`platform_breakdown` 与 `per_question_rank_matrix` 结构化保存。所有 `question_type="reputation_issue"` 或 `ranking_metric_eligible=false` 的样本必须被排除出上述聚合指标，仅保留在矩阵中并转入 `reputation_issue_diagnostics`。

| 分桶 | 字段 | 解释 |
| :--- | :--- | :--- |
| 第 1 位 | `rank_1` | 首位心智占位 |
| 2-3 位 | `rank_2_3` | 高注意力区 |
| 4-5 位 | `rank_4_5` | 仍在主要答案区但优势较弱 |
| 6-10 位 | `rank_6_10` | 边缘可见 |
| 11+ / 未提及 | `rank_11_plus` | 基本不可见或未进入推荐列表 |

### 2.3 评分标准

| 分数段 | 含义 | 典型表现 |
| :--- | :--- | :--- |
| 90-100 | 卓越 | 几乎所有 AI 回答都提及品牌，且多数排在前 2 位 |
| 70-89 | 优秀 | 大部分回答提及品牌，位次较靠前 |
| 50-69 | 一般 | 约半数回答提及品牌，位次不稳定 |
| 30-49 | 较差 | 少数回答提及品牌，位次靠后 |
| 0-29 | 极差 | 几乎不被 AI 提及 |

### 2.4 按平台加权

不同 AI 平台的权重按用户量和影响力分配：

| 平台 | 建议权重 | 原因 |
| :--- | :--- | :--- |
| ChatGPT | 30% | 全球用户量最大 |
| Perplexity | 20% | 搜索导向，引用率影响大 |
| Claude | 15% | 专业用户群体 |
| Gemini | 15% | Google 生态整合 |
| Kimi/文心 | 20% | 国内市场覆盖 |

## 三、D2 语义准确度（Semantic Accuracy）

### 3.1 定义

衡量 AI 回答中关于品牌的描述是否与品牌事实图谱（S1）中的硬事实一致。

### 3.2 计算公式

```
事实正确率 = 正确描述数 / AI回答中的品牌描述总数 × 100

信息完整度 = AI回答中包含的关键信息数 / S1事实图谱中的关键信息总数 × 100

D2 = 事实正确率 × 0.7 + 信息完整度 × 0.3
```

### 3.3 事实核查方法

将 AI 回答中的每条品牌描述与 S1 事实图谱对比：

| 核查项 | 正确标准 | 错误示例 |
| :--- | :--- | :--- |
| 公司名称 | 与 `facts.company_info.full_name` 一致 | 名称错误或混淆 |
| 成立时间 | 与 `facts.company_info.established_date` 一致 | 年份错误 |
| 产品描述 | 与 `facts.products` 一致 | 产品功能描述错误 |
| 资质信息 | 与 `facts.certifications` 一致 | 资质编号错误或过期 |
| 客户信息 | 与 `facts.clients` 一致 | 客户名称或案例错误 |

## 四、D3 E-E-A-T 信号

### 4.1 定义

评估 AI 回答中是否体现了品牌的 Experience（经验）、Expertise（专业性）、Authoritativeness（权威性）和 Trustworthiness（可信度）。

### 4.2 四维评估

| 子维度 | 评估标准 | 正面信号 | 负面信号 |
| :--- | :--- | :--- | :--- |
| Experience | AI 是否提及品牌的实际案例 | "XX 品牌曾为 YY 客户提供..." | 无具体案例 |
| Expertise | AI 是否提及专业资质/技术 | "拥有 CMA 认证..." | 无专业描述 |
| Authoritativeness | AI 是否将品牌描述为权威 | "行业领先的..." | "一般的..." |
| Trustworthiness | AI 是否引用可信来源 | "根据官方数据..." | 无来源引用 |

### 4.3 计算公式

```
每个子维度：0-25 分
D3 = Experience分 + Expertise分 + Authoritativeness分 + Trustworthiness分
```

## 五、D4 竞品对比（Competitive Position）

### 5.1 定义

衡量品牌与竞品在 AI 回答中的相对位置和评价差异。

### 5.2 计算公式

```
优势比 = 品牌排名优于竞品的回答数 / 含竞品对比的回答数

评价差 = 品牌正面评价比例 - 竞品正面评价比例

D4 = 优势比 × 60 + (评价差 + 1) / 2 × 40
```

### 5.3 竞品位次差诊断

D4 必须同步输出 `competitor_rank_gap = 品牌平均位次 - 最强竞品平均位次`。当该值为正，说明品牌在共同问题中整体落后竞品；当该值为负，说明品牌整体领先。问题级矩阵中必须保留 `top_competitor`、`top_competitor_rank` 与 `rank_gap`，以便 S5.5 判断“语义占优”究竟来自首位提及、Top3 稳定性，还是竞品缺席。

## 六、D5 用户意图覆盖（Intent Coverage）

### 6.1 定义

衡量 AI 回答覆盖 S2 营销图谱中定义的用户意图类型的完整度。

### 6.2 计算公式

```
意图覆盖率 = AI回答覆盖的意图类型数 / S2定义的意图类型总数 × 100

话题覆盖率 = AI回答覆盖的核心话题数 / S2场景树中核心话题总数 × 100

D5 = 意图覆盖率 × 0.5 + 话题覆盖率 × 0.5

> **v3.0 说明**：原问题阶段覆盖率已替换为话题覆盖率。场景树架构下，问题阶段不再作为强制分桶维度，而是作为每个变体的可选标签。话题覆盖更能反映品牌在 AI 搜索中的场景广度。
```

## 七、D6 负面舆情（Negative Sentiment）

### 7.1 定义

衡量 AI 回答中负面信息的出现频率、问题严重度和品牌的应对能力。分数越高表示负面情况越少。D6 是直接点名品牌的缺点、问题、投诉、口碑、风险、负面评价类题目的主要承接指标，必须优先读取 `ranking_position_diagnostics.reputation_issue_diagnostics`；这类样本不得反向进入 D1 可见度或排名分母。

### 7.2 计算公式

```
负面出现率 = 舆情类问题中含负面信息的回答数 / 实际上传的舆情类问题回答数
# 若本轮没有舆情类问题，再退回使用全样本负面回答占比，并在报告中注明口径

负面严重度 = Σ(每条负面信息的严重度评分) / 负面信息总数
  严重度：高=3, 中=2, 低=1

D6 = 100 - (负面出现率 × 50 + 负面严重度 / 3 × 50)
```

## 八、D7 定位 Gap（Positioning Gap）

### 8.1 定义

衡量 AI 实际呈现的品牌形象与 S4 定义的理想定位之间的偏差。分数越高表示偏差越小。

### 8.2 7 维 Gap 框架

| Gap 维度 | 对标来源 | 计算方法 |
| :--- | :--- | :--- |
| 人群 Gap | S4 `target_audience` | AI 回答隐含受众 vs 理想受众的匹配度 |
| 品类 Gap | S4 `category` | AI 归类 vs 理想品类的匹配度 |
| 差异点 Gap | S4 `differentiator` | AI 描述的特点 vs 理想差异点的匹配度 |
| 功能价值 Gap | S4 `functional_value` | AI 提及的功能 vs 理想功能价值的匹配度 |
| 情感价值 Gap | S4 `emotional_value` | AI 传达的情感 vs 理想情感价值的匹配度 |
| 证据 Gap | S4 `evidence` | AI 引用的证据 vs 理想证据的匹配度 |
| 话语 Gap | S6 话语基准（如有） | AI 用词 vs 理想话语的匹配度 |

### 8.3 计算公式

```
每个 Gap 维度：0-100（0=完全偏离，100=完全一致）
D7 = Σ(各维度 Gap 分) / 7
```

## 九、综合评分与等级

```
综合分 = D1×0.20 + D2×0.15 + D3×0.15 + D4×0.15 + D5×0.10 + D6×0.10 + D7×0.15
```

| 综合分 | 等级 | 建议行动 |
| :--- | :--- | :--- |
| 90-100 | A+ | 维持现状，持续监测 |
| 80-89 | A | 微调优化，重点关注低分维度 |
| 70-79 | B | 系统性优化，制定 3 个月改进计划 |
| 60-69 | C | 全面优化，制定 6 个月改进计划 |
| 0-59 | D | 紧急重建，需要全面的品牌内容策略 |
