## 附录：话语 Token JSON 文件说明

话语 Token JSON（`S6_{brand}_话语token.json`）是本手册的机器可执行版本，包含以下字段：

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `tone_tokens` | object | 4 维度打分 + 语调描述 |
| `messaging_house` | object | 信息屋结构 |
| `high_freq_words` | array | 高频词列表 |
| `banned_words` | array | 禁用词列表 |
| `sentence_patterns` | array | 句式模板 |
| `slogan_candidates` | array | 品牌口号候选 |
| `do_dont_pairs` | array | Do/Don't 对照 |
