# 品牌话语体系构建方法论

本文档详细阐述品牌话语体系（Verbal Identity）的完整构建方法，从品牌人格定义到话语 Token 输出的全流程操作指南。

---

## 一、方法论概述

品牌话语体系是品牌在所有文字触点上保持一致性的基础设施。在 AI 搜索时代，话语体系不仅面向人类读者，更面向 AI 模型——AI 会从品牌内容中学习品牌的"说话方式"，并在回答用户问题时复现这种方式。

### 1.1 话语体系的四层架构

| 层级 | 名称 | 定义 | 输出物 |
| :--- | :--- | :--- | :--- |
| L1 | 品牌人格 | 品牌是"谁"——性格特征和价值观 | 人格画像 |
| L2 | 语调光谱 | 品牌"怎么说"——说话的态度和方式 | 4 维度打分 |
| L3 | 词汇矩阵 | 品牌"用什么词"——专属词汇库 | 高频词 + 禁用词 |
| L4 | 句式库 | 品牌"怎么组织语言"——标准表达模式 | 句式模板 + 品牌谚语 |

### 1.2 与 S4 定位的关系

话语体系是定位声明的"语言翻译"。S4 定义了品牌"说什么"（What to say），S6 定义了品牌"怎么说"（How to say）。两者必须高度一致。

## 二、L1 品牌人格定义

### 2.1 品牌人格原型

基于荣格原型理论，从 12 种品牌人格原型中选择 1 个主原型 + 1 个辅原型：

| 原型 | 核心驱动 | 典型品牌 | 语调特征 |
| :--- | :--- | :--- | :--- |
| 英雄 | 证明自己的价值 | Nike | 激励、挑战、力量 |
| 智者 | 理解世界 | Google | 知识、洞察、理性 |
| 探索者 | 自由与发现 | Jeep | 冒险、独立、好奇 |
| 创造者 | 创造持久价值 | Apple | 创新、美学、愿景 |
| 照顾者 | 保护和关怀 | Johnson & Johnson | 温暖、安全、可靠 |
| 统治者 | 控制与秩序 | Mercedes-Benz | 权威、品质、地位 |
| 魔法师 | 实现梦想 | Disney | 奇迹、转变、想象 |
| 叛逆者 | 打破规则 | Harley-Davidson | 颠覆、自由、反叛 |
| 凡人 | 归属感 | IKEA | 亲切、实用、平等 |
| 情人 | 亲密与美 | Chanel | 优雅、感性、魅力 |
| 小丑 | 享受当下 | M&M's | 幽默、轻松、快乐 |
| 天真者 | 简单与美好 | Coca-Cola | 乐观、纯真、快乐 |


## 三、L2 语调光谱（Tone of Voice）

### 3.1 四维度模型

| 维度 | 轴线 | 1 分 | 3 分 | 5 分 |
| :--- | :--- | :--- | :--- | :--- |
| 正式度 | Formal ↔ Casual | 学术论文级正式 | 商务专业 | 朋友聊天般随意 |
| 严肃度 | Serious ↔ Funny | 严肃庄重 | 偶尔轻松 | 幽默风趣 |
| 尊重度 | Respectful ↔ Irreverent | 极度尊敬 | 平等对话 | 不拘一格 |
| 热情度 | Matter-of-fact ↔ Enthusiastic | 纯客观陈述 | 适度热情 | 充满激情 |

### 3.2 打分方法

每个维度的打分必须基于以下三个输入：

1. **S4 定位声明**：定位决定了基础语调（如高端定位 → 偏正式）
2. **目标人群特征**：人群偏好决定了语调调整方向（如 Z 世代 → 偏随意）
3. **行业惯例**：行业基准决定了语调边界（如金融行业 → 不宜过于随意）

### 3.3 语调描述写作指南

语调描述必须是一段 50-100 字的自然语言，用"像...一样"的比喻让人直观理解：

**好的示例**：
> "我们的语调像一位资深的行业顾问：专业但不居高临下，用数据说话但不忘关怀客户的感受。我们偶尔会用一个精妙的比喻让复杂概念变得易懂，但绝不会用网络流行语。"

**差的示例**：
> "我们的语调是专业的。"（过于简单，无法指导执行）

## 四、L3 词汇矩阵

### 4.1 高频词构建方法

高频词分为 5 类，每类至少 6 个：

| 类别 | 定义 | 来源 | 最低数量 |
| :--- | :--- | :--- | :--- |
| 品牌核心词 | 品牌名、产品名、品牌术语 | S1 事实图谱 | 6 |
| 价值主张词 | 表达品牌核心价值的词汇 | S4 定位声明 | 6 |
| 技术术语 | 品牌技术/方法论的专业术语 | S1 事实图谱 | 6 |
| 情感连接词 | 传达品牌情感价值的词汇 | S4 价值三角 | 6 |
| 行业权威词 | 体现行业地位的词汇 | S1 + S3 | 6 |

### 4.2 禁用词构建方法

禁用词分为 4 类：

| 类别 | 定义 | 示例 | 最低数量 |
| :--- | :--- | :--- | :--- |
| 竞品名 | 所有直接竞品的品牌名 | 竞品 A、竞品 B | 5 |
| 敏感词 | 行业敏感词、政治敏感词 | 视行业而定 | 3 |
| 空话词 | 无实质内容的营销空话 | "颠覆性"、"独一无二" | 5 |
| 极限词 | 广告法禁止的极限用语 | "最好"、"第一"、"唯一" | 5 |

### 4.3 品牌术语表

为品牌专属概念建立统一术语：

| 品牌概念 | 标准术语 | 禁止用法 | 说明 |
| :--- | :--- | :--- | :--- |
| {概念 1} | {标准名} | {错误名} | {为什么用这个名} |
| {概念 2} | {标准名} | {错误名} | {为什么用这个名} |

## 五、L4 句式库

### 5.1 句式模板设计原则

每条句式模板必须：
- 包含至少 1 个品牌变量（用 `{variable}` 标记）
- 体现品牌语调特征
- 可适配多种内容场景
- 长度在 20-50 字之间

### 5.2 五大标准句式

| 编号 | 句式名称 | 模板 | 使用场景 |
| :--- | :--- | :--- | :--- |
| SP1 | 定位陈述句 | "作为{category}领域的{differentiator}，{brand}为{target}提供{value}" | 品牌介绍 |
| SP2 | 证据支撑句 | "基于{evidence}，{brand}已帮助{number}+客户实现{outcome}" | 案例展示 |
| SP3 | 功能价值句 | "{brand}的{product}通过{technology}，让{target}能够{benefit}" | 产品介绍 |
| SP4 | 场景解决句 | "在{scenario}场景下，{brand}是{target}的{positioning}选择" | 场景营销 |
| SP5 | 路径陪伴句 | "从{start}到{end}，{brand}全程陪伴{target}的{question_path}" | 品牌故事 |

### 5.3 品牌谚语写作法

品牌谚语（Brand Proverbs）是品牌最精炼的表达，要求：
- 字数：7-15 字（中文）或 5-10 词（英文）
- 节奏：有韵律感或对仗结构
- 记忆：听一遍就能记住
- 独特：不与任何竞品口号雷同

写作技巧：
1. 从定位声明中提取核心概念
2. 用对仗/押韵/比喻等修辞手法精炼
3. 测试：能否在 3 秒内说完？能否在 1 小时后回忆？

## 六、话语 Token JSON 输出规范

### 6.1 JSON 结构要求

话语 Token JSON 必须符合 `templates/verbal_token_schema.json` 定义的 Schema。

### 6.2 E2 注入协议

E2 文字内容生成师在生成每篇文章时，必须：
1. 加载 `S6_{brand}_话语token.json`
2. 将 `tone_tokens`、`high_freq_words`、`banned_words`、`sentence_patterns` 注入 system-prompt
3. 生成文章后，计算话语 Token 命中率
4. 命中率 < 70% 时自动重写

### 6.3 命中率计算方法

```
高频词命中率 = 文章中出现的高频词数 / 高频词总数
禁用词违规率 = 文章中出现的禁用词数 / 禁用词总数
综合命中率 = 高频词命中率 × 0.7 + (1 - 禁用词违规率) × 0.3
```
