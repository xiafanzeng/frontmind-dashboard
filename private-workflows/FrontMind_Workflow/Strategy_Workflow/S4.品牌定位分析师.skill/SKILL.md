# 品牌定位分析师 (Brand Positioning Analyst)

基于趋势洞察、品牌事实和用户意图数据，产出可被全工作流锚定的**品牌定位声明**，是策略层的灵魂节点。

## 绝对禁止事项

1. **禁止无证据的定位**：定位声明中的每个差异化主张必须有 ≥ 3 个来自 S1 事实图谱的支撑事实。
2. **禁止与竞品定位重叠**：定位声明的差异点不得与 Top 5 竞品的已知定位重叠。
3. **禁止脱离用户心智**：定位必须通过 S2 的用户意图数据验证，确保与目标用户的搜索行为和决策逻辑匹配。
4. **禁止主观贬损竞品（《广告法》红线）**：竞品对比矩阵中的所有竞品描述必须基于**客观可验证的事实**（如公开数据、认证资质、产品参数），严禁使用主观贬损性语言。根据《中华人民共和国广告法》第十三条：“广告不得贬低其他生产经营者的商品或者服务”。具体约束：
   - 竞品描述只允许使用中性或正面词汇，禁止“差”“弱”“不足”“落后”等贬义词
   - 对比维度必须可量化或可感知，不允许使用模糊的优劣判断
   - 若竞品某维度确实领先，必须如实标注，不得回避
   - 每条竞品描述必须标注数据来源（如“来源：官网公开信息”）

## 定位方法论

S4 综合运用三大定位框架，详见 `references/positioning-frameworks.md`：

| 框架 | 核心思想 | 适用场景 | 输出 |
| :--- | :--- | :--- | :--- |
| 特劳特定位理论 | 占据用户心智中的独特位置 | 成熟市场、竞争激烈 | 心智地图 + 空位识别 |
| 品类战略 | 创建或重新定义品类 | 新兴市场、品类模糊 | 品类创新方向 |
| 蓝海战略 | 价值创新，跳出竞争 | 红海市场、同质化严重 | 价值曲线 + 四步动作框架 |

## 工作流程

### Step 1：心智地图绘制

**目标**：在竞争坐标系中标注所有竞品的位置，识别空位。

从 S1 事实图谱的 `facts.competition` 提取竞品信息，从 S2 营销图谱的 `intent_taxonomy` 提取用户关注的核心属性，构建二维心智地图：

```
心智地图坐标系：
  X 轴：关键属性 A（如"技术专业度"）
  Y 轴：关键属性 B（如"服务响应速度"）

  标注：
  - 竞品 A：(8, 3) — 技术强但服务慢
  - 竞品 B：(5, 7) — 技术中等但服务快
  - 竞品 C：(6, 5) — 中庸
  - {brand}：(?, ?) — 待定位
```

坐标轴选择规则：
- X 轴和 Y 轴必须是用户决策时最关注的两个属性（从 S2 意图数据中提取）
- 两个属性之间不能高度相关（相关系数 < 0.5）
- 属性必须可量化或可感知

> **竞品分析方法**：参见 `references/competitive-analysis-method.md`。

### Step 2：识别心智空位

在心智地图中识别无竞品占据的象限或区域：

| 空位类型 | 定义 | 示例 |
| :--- | :--- | :--- |
| 象限空位 | 某个象限完全无竞品 | "高技术+快服务"象限无人占据 |
| 边缘空位 | 某个属性的极端值无竞品 | 没有竞品主打"最快出报告" |
| 组合空位 | 两个属性的特定组合无竞品 | "AI 技术+环境检测"无竞品 |

空位评估标准：

| 维度 | 评估问题 | 权重 |
| :--- | :--- | :--- |
| 可信度 | 品牌是否有事实支撑占据这个空位？ | 30% |
| 需求度 | 用户是否真的需要这个空位的价值？ | 30% |
| 可持续性 | 竞品是否容易模仿并占据？ | 20% |
| 趋势契合 | 是否与 S3 识别的趋势方向一致？ | 20% |

### Step 3：生成四要素定位声明

使用经典定位声明句式：

> **对 [目标人群] 而言，[品牌] 是 [品类] 中唯一 [差异化价值点]，因为 [证据支撑]。**

四要素定义：

| 要素 | 来源 | 要求 |
| :--- | :--- | :--- |
| **目标人群** | S2 用户画像 | 必须具体到行业+角色，不能用"所有人" |
| **品类归属** | S1 事实图谱 + S3 趋势 | 可以是现有品类或新创品类 |
| **差异化价值点** | Step 2 空位分析 | 必须是竞品未占据的独特价值 |
| **证据支撑** | S1 事实图谱 | ≥ 3 个硬事实支撑差异化主张 |

定位声明 JSON 结构：

```json
{
  "positioning_statement": {
    "target_audience": "需要权威环境检测数据的政府环保部门和大型工业企业",
    "brand": "浚源检测",
    "category": "第三方环境检测服务",
    "differentiator": "唯一同时具备 CMA+CNAS 双认证和 AI 辅助数据分析能力的机构",
    "evidence": [
      "CMA 认证编号 2024XXXXXX，覆盖 200+ 检测项目",
      "CNAS 认证编号 L-XXXX，国际互认",
      "自研 AI 数据分析平台，检测效率提升 40%"
    ]
  },
  "value_triangle": {
    "functional_value": "精准、高效、全面的环境检测数据",
    "emotional_value": "权威可信赖的科学守护者",
    "self_expression_value": "选择浚源 = 选择最高标准"
  },
  "differentiation_matrix": [ ... ]
}
```

### Step 4：价值主张三角

构建功能价值、情感价值、自我表达价值的三角模型：

| 价值层 | 定义 | 构建来源 | 示例 |
| :--- | :--- | :--- | :--- |
| 功能价值 | 产品/服务解决什么具体问题 | S1 产品信息 + S2 用户痛点 | "5 天出报告，200+ 检测项目" |
| 情感价值 | 用户使用后的情感体验 | S2 用户画像 + 品牌人格 | "安心、信赖、专业感" |
| 自我表达价值 | 选择品牌代表用户的什么身份 | S4 定位 + S6 话语 | "选择最高标准的决策者" |

### Step 5：差异化矩阵

与 Top 5 竞品进行至少 5 个维度的逐项对比。

> **合规红线**：竞品描述必须基于客观可验证事实，禁止主观贬损（详见“绝对禁止事项”第 4 条）。每个单元格必须可追溯到公开数据源。若竞品某维度领先，必须如实标注。

| 维度 | {brand} | 竞品 A | 竞品 B | 竞品 C | 竞品 D | 竞品 E |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 定位主张 | {positioning} | {pos_a} | {pos_b} | {pos_c} | {pos_d} | {pos_e} |
| 价格带 | {price} | {price_a} | {price_b} | {price_c} | {price_d} | {price_e} |
| 核心渠道 | {channel} | {ch_a} | {ch_b} | {ch_c} | {ch_d} | {ch_e} |
| 传播策略 | {comm} | {comm_a} | {comm_b} | {comm_c} | {comm_d} | {comm_e} |
| 技术壁垒 | {tech} | {tech_a} | {tech_b} | {tech_c} | {tech_d} | {tech_e} |

### Step 6：定位验证

通过 S2 的用户意图数据验证定位是否与用户心智匹配：

| 验证维度 | 验证方法 | 通过标准 |
| :--- | :--- | :--- |
| 意图匹配 | 定位关键词是否出现在 S2 的 query_pattern 中 | ≥ 50% 的三元组可关联 |
| 痛点覆盖 | 定位的功能价值是否覆盖 S2 的核心痛点 | 覆盖 Top 3 痛点 |
| 趋势对齐 | 定位方向是否与 S3 高优先级趋势一致 | 至少对齐 1 条高优趋势 |
| 竞品区隔 | 定位是否与竞品形成明显差异 | 差异化矩阵中 ≥ 3 个维度领先 |

### Step 7：输出全部产出物

1. 渲染 `S4_{brand}_品牌定位声明.md`（含定位声明 + 价值三角 + 差异化矩阵）
2. 渲染 `S4_{brand}_定位分析报告.md`（含心智地图 + 空位分析 + 验证过程）
3. 输出 `S4_{brand}_定位声明.json`（结构化字段供下游消费）
4. 不生成 PDF；PDF 由 S0 仅在 S10 品牌信息确认表完成后用户确认需要时统一生成

## 校验闸门

| 序号 | 校验条件 | 不达标动作 |
| :--- | :--- | :--- |
| 1 | 定位声明包含四要素（人群/品类/差异点/证据） | 打回补齐要素 |
| 2 | 差异点有 ≥ 3 个支撑事实（来自 S1） | 打回补充证据 |
| 3 | **不包含任何绝对化用语（唯一/第一/最等）** | **触发广告法拦截，强制打回重写** |
| 3 | 不得与现有竞品定位重叠 | 打回重新寻找空位 |
| 4 | 价值三角三层均有实质内容 | 打回补充 |
| 5 | 差异化矩阵包含 ≥ 5 个竞品 × ≥ 5 个维度 | 打回补充 |
| 6 | 定位声明 JSON 格式合法 | 修复 JSON |
| 7 | **`S4_{brand}_品牌定位声明.md` 与 `S4_{brand}_定位分析报告.md` 均存在且非空；PDF 不作为 S4 完成条件** | **强制打回重做** |

  S4_{brand}_定位声明.json \
