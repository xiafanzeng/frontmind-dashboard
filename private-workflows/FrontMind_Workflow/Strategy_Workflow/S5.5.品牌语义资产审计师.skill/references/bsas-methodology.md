# BSAS 五维评估方法论详解

## 一、理论基础

品牌语义资产评分（Brand Semantic Asset Score, BSAS）融合了以下学术与行业方法论：

### 1.1 Semantic Brand Score (SBS)

> Fronzetti Colladon, A. (2018). The Semantic Brand Score. *Journal of Business Research*, 88, 150-160.

SBS 通过文本挖掘和社会网络分析，从三个维度量化品牌在文本语料中的语义地位：
- **Prevalence（流行度）**：品牌在语料中被提及的频率
- **Diversity（多样性）**：品牌关联的语义主题多样性
- **Connectivity（连接性）**：品牌在语义网络中的中介中心性

BSAS 的维度一（可见度）和维度三（多样性）直接借鉴了 SBS 的 Prevalence 和 Diversity 概念，但将数据源从传统文本语料扩展到了全网搜索 + AI 搜索的双生态。

### 1.2 AI Visibility Score

AI 可见性评分（如 TigerTracks 的 AIS）关注品牌在 AI 回答引擎中的存在感：
- **Mention Rate**：AI 回答中品牌被提及的频率
- **Position**：品牌在 AI 回答中的位置（首位 vs 末位）
- **Sentiment**：AI 回答中品牌相关内容的情感倾向
- **Accuracy**：AI 回答中品牌信息的准确度

BSAS 的维度一部分子指标（AI 搜索可见率）和维度五（竞品占优度）吸收了 AIS 的核心理念。

### 1.3 Narrative Alignment Score

叙事对齐评分关注品牌期望传达的故事与实际被感知的故事之间的一致性：
- **Message Consistency**：核心信息在各渠道的一致性
- **Tone Alignment**：语调与品牌标准的吻合度
- **Story Completeness**：品牌故事的完整性

BSAS 的维度二（语义一致性）直接对应 Narrative Alignment 的核心理念。

## 二、数据采集方法

### 2.1 全网搜索数据采集

| 数据类型 | 采集方法 | 工具/平台 |
| :--- | :--- | :--- |
| 搜索结果排名 | 基于 S2 核心关键词搜索 | Google/百度/Bing 前 20 结果 |
| 内容类型分布 | 分析搜索结果中各格式占比 | 手动分类 + 自动化标注 |
| 品牌提及密度 | 统计搜索结果中品牌名出现频次 | 文本分析 |
| 竞品对比数据 | 对竞品执行同关键词搜索 | 同上 |

### 2.2 AI 搜索数据采集

| 数据类型 | 采集方法 | 工具/平台 |
| :--- | :--- | :--- |
| AI 回答中品牌提及 | 复用 S5 监测数据 | ChatGPT/Claude/Gemini/DeepSeek 等 |
| 品牌信息准确度 | 对比 S1 事实图谱与 AI 回答 | 人工校验 + 自动化比对 |
| 定位主张传达度 | 对比 S4 定位声明与 AI 回答 | 语义相似度计算 |
| 竞品提及对比 | 统计同问题下竞品被提及情况 | 复用 S5 竞品诊断数据 |

### 2.3 社交/垂直平台数据采集

| 数据类型 | 采集方法 | 工具/平台 |
| :--- | :--- | :--- |
| 品牌讨论量 | 搜索品牌名相关内容 | 小红书/知乎/微博/抖音/B站 |
| 内容质量评估 | 抽样评估内容深度和准确性 | 人工评估 |
| 用户评价情感 | 分析评价内容情感倾向 | 情感分析 |

## 三、评分计算规则

### 3.1 原始分值标准化

所有子指标的原始值需标准化到 0-1 区间，再乘以对应权重得到最终分值：

```
子指标得分 = min(原始比率, 1.0) × 子指标满分
```

**特殊规则**：
- 当原始比率超过 1.0 时，封顶为满分（不超过该子指标的权重上限）
- 当数据缺失时，该子指标记为 0 分，并在报告中标注"数据缺失"
- 竞品对比类指标使用相对排名法：品牌排名 ÷ (竞品数 + 1)

### 3.2 维度得分计算

```
维度得分 = Σ(该维度下所有子指标得分)
```

### 3.3 总分计算

```
BSAS 总分 = 维度一得分 + 维度二得分 + 维度三得分 + 维度四得分 + 维度五得分
```

满分 = 30 + 20 + 20 + 15 + 15 = 100 分

### 3.4 等级判定

| 分数区间 | 等级 | 行业参考 |
| :--- | :--- | :--- |
| 80-100 | A（优秀） | 行业头部品牌，语义资产体系完善 |
| 60-79 | B（良好） | 中上水平，有明确的建设方向 |
| 40-59 | C（及格） | 行业平均水平，需系统性提升 |
| 20-39 | D（较差） | 低于行业平均，语义存在感薄弱 |
| 0-19 | E（缺失） | 几乎无语义资产，需从零建设 |

## 四、与 S5 AI 可见性诊断的关系

| 维度 | S5 AI 可见性诊断 | S5.5 品牌语义资产打分 |
| :--- | :--- | :--- |
| 评估范围 | 仅 AI 搜索引擎 | 全网搜索 + AI 搜索 + 社交平台 |
| 评估深度 | 是否被提及（有/无） | 提及的质量、一致性、深度、权威性 |
| 评估视角 | 品牌可见性（被动） | 品牌语义资产厚度（主动） |
| 输出形式 | 7 维诊断 + Gap 报告 | 5 维评分卡 + 审计报告 + 提升路径 |
| 核心问题 | "品牌被看见了吗？" | "品牌的语义资产质量如何？" |

两者是**递进关系**：S5 发现"可见性问题"，S5.5 量化"资产厚度"，共同为 S6/S8 的内容建设提供方向。

## 五、季度复评机制

BSAS 不是一次性评估，而是应定期复评以量化内容执行效果：

| 复评频率 | 触发方式 | 目的 |
| :--- | :--- | :--- |
| 首次评估 | S5 完成后自动触发 | 建立基线 |
| 季度复评 | 外部监测层定期触发 | 量化提升效果 |
| 事件驱动 | 重大内容发布后 | 评估单次行动效果 |

复评时，对比历史评分，生成趋势图和提升率报告。
