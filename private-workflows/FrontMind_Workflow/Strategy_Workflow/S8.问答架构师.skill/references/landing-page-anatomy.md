# 落地页五大标准模块结构

本文档定义 FrontMind 策略层推导的落地页蓝图标准结构，为 S8 问答架构师和外部官网/落地页改造团队提供结构参考。

---

## 1. 落地页设计原则

落地页蓝图是**策略层产出**，不是设计稿。它定义的是"页面应该包含什么内容"和"内容的逻辑顺序"，而非视觉设计。

| 原则 | 说明 |
| :--- | :--- |
| 策略驱动 | 每个模块的内容必须来自策略层产出（S1-S8） |
| GEO 优先 | 页面结构必须有利于 AI 抓取和引用 |
| 问题路径对齐 | 页面模块顺序对应用户问题路径从认知到行动的路径 |
| Schema 友好 | 每个模块应标注推荐的 Schema.org 标记类型 |

---

## 2. 五大标准模块

### 模块 1：首屏（Hero Section）

| 属性 | 说明 |
| :--- | :--- |
| 策略来源 | S4 品牌定位声明 |
| 核心内容 | 品牌名 + 一句话定位 + 核心视觉 + 主 CTA |
| Schema 标记 | `Organization` / `Brand` |
| 问题阶段 | 认知 → 考虑 |

**内容规格**：
- 标题：S4 定位声明的"一句话版本"（≤ 15 字）
- 副标题：S4 差异化描述（≤ 30 字）
- 主 CTA：根据业务类型选择（"立即咨询" / "免费试用" / "了解更多"）
- 背景视觉：S7 视觉 Prompt 包中的"品牌主视觉"

### 模块 2：价值主张（Value Proposition）

| 属性 | 说明 |
| :--- | :--- |
| 策略来源 | S4 定位声明 + S6 话语手册 |
| 核心内容 | 3-4 个核心价值点，每个配图标 + 标题 + 描述 |
| Schema 标记 | `ItemList` + `ListItem` |
| 问题阶段 | 考虑 |

**内容规格**：
- 每个价值点：图标 + 标题（≤ 8 字）+ 描述（≤ 50 字）
- 价值点来源：S4 定位声明中的"差异化支撑点"
- 话语风格：S6 话语手册中的"品牌语调"
- 数量：3-4 个（不超过 5 个）

### 模块 3：信任证明（Social Proof）

| 属性 | 说明 |
| :--- | :--- |
| 策略来源 | S1 品牌事实图谱 + S6 信任状话语 |
| 核心内容 | 客户 Logo 墙 / 数据成就 / 客户证言 / 媒体报道 |
| Schema 标记 | `Review` / `AggregateRating` |
| 问题阶段 | 考虑 → 决策 |

**内容规格**：
- 数据成就：3-4 个关键数字（如"服务 500+ 企业"、"覆盖 30 个城市"）
- 客户证言：2-3 条（含姓名、职位、公司、证言内容）
- 媒体报道：列出被报道的媒体 Logo
- 数据来源：S1 品牌事实图谱中的 `evidence` 字段

### 模块 4：常见问题（FAQ）

| 属性 | 说明 |
| :--- | :--- |
| 策略来源 | S8 问答树 |
| 核心内容 | 5-8 个高频问题 + 标准答案 |
| Schema 标记 | `FAQPage` + `Question` + `Answer` |
| 问题阶段 | 考虑 → 决策 → 使用 |

**内容规格**：
- 问题选择：从 S8 问答树中选择"决策"和"使用"阶段的高频问题
- 答案格式：简洁直接，≤ 150 字/条
- FAQ Schema：必须使用 `FAQPage` 结构化标记（这是 GEO 最高价值的 Schema 类型之一）
- 排序：按用户提问频率降序

### 模块 5：行动呼吁（CTA）

| 属性 | 说明 |
| :--- | :--- |
| 策略来源 | S8 问题阶段 + S9 业务赋能建议 |
| 核心内容 | 总结性话语 + 主 CTA + 辅助 CTA |
| Schema 标记 | `Action` |
| 问题阶段 | 决策 → 行动 |

**内容规格**：
- 总结语：呼应首屏定位，强化品牌印象（≤ 30 字）
- 主 CTA：与首屏一致
- 辅助 CTA：如"下载白皮书"、"预约演示"、"查看案例"
- 联系方式：电话 / 邮箱 / 在线客服入口

---

## 3. GEO 优化要点

| 优化项 | 说明 |
| :--- | :--- |
| Schema.org 标记 | 每个模块必须标注推荐的 Schema 类型 |
| 语义结构 | 使用正确的 HTML 语义标签（h1/h2/h3/section/article） |
| FAQ 结构化 | FAQ 模块必须使用 FAQPage Schema |
| 实体关联 | 页面内容应包含品牌实体的完整信息（名称、描述、Logo、联系方式） |
| 内链策略 | FAQ 答案中应链接到对应的详细内容页 |

---

## 4. 落地页蓝图输出格式

S8 输出的 `S8_{brand}_落地页蓝图.md` 应包含以下结构：

```markdown
# {brand} 落地页蓝图

## 页面目标
{一句话描述页面目标}

## 模块 1：首屏
- 标题：{...}
- 副标题：{...}
- 主 CTA：{...}
- 视觉参考：{S7 Prompt 编号}

## 模块 2：价值主张
- 价值点 1：{标题} — {描述}
- 价值点 2：{标题} — {描述}
- 价值点 3：{标题} — {描述}

## 模块 3：信任证明
- 数据成就：{...}
- 客户证言：{...}
- 媒体报道：{...}

## 模块 4：常见问题
- Q1：{问题} → A1：{答案}
- Q2：{问题} → A2：{答案}
- ...

## 模块 5：行动呼吁
- 总结语：{...}
- 主 CTA：{...}
- 辅助 CTA：{...}

## Schema 标记建议
{各模块推荐的 Schema.org 标记类型}
```
