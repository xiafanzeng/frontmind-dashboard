# 五段用户问题路径框架

本文档定义 FrontMind 策略层使用的五段用户问题路径模型，为 S8 问答架构师提供问题路径拆解的标准框架。

---

## 1. 问题路径模型总览

| 阶段 | 英文 | 用户心理 | 核心问题类型 | AI 搜索行为 |
| :--- | :--- | :--- | :--- | :--- |
| 认知 | Awareness | "我有一个需求/问题" | 品类科普、趋势了解 | "什么是 XX？""XX 有哪些类型？" |
| 考虑 | Consideration | "有哪些选择？" | 对比评测、选购指南 | "XX 和 YY 哪个好？""XX 怎么选？" |
| 决策 | Purchase | "我要选哪一个？" | 产品详解、价格、案例 | "XX 品牌怎么样？""XX 值不值得买？" |
| 使用 | Retention | "怎么用好？" | 教程、FAQ、最佳实践 | "XX 怎么用？""XX 常见问题" |
| 推荐 | Advocacy | "值得推荐吗？" | 用户故事、行业影响力 | "XX 好用吗？""有什么替代品？" |

---

## 2. AI 搜索时代的问题路径特征

### 2.1 问题路径压缩

传统营销漏斗中，用户可能需要数周完成从认知到决策的问题路径。在 AI 搜索时代，用户可以在一次对话中完成多个阶段的跳跃。

**影响**：每个阶段的内容必须能够独立成立，同时也能在对话上下文中自然衔接。

### 2.2 信息聚合

AI 会将多个来源的信息聚合为一个回答。品牌不再只需要"排名靠前"，而需要"被 AI 引用"。

**影响**：内容必须具有高度结构化和可引用性（E-E-A-T 信号）。

### 2.3 对话式深入

用户会通过追问深入了解。一个"认知"阶段的问题可能通过追问直接跳到"决策"阶段。

**影响**：问答树的设计必须考虑追问路径，每个问题都应有"下一步可能的追问"。

## 3. 各阶段问题挖掘方法

### 3.1 认知阶段（Awareness）

**问题来源**：
- S2 营销图谱中的品类认知类三元组
- 行业通用科普问题
- S3 趋势报告中的新兴话题

**问题模板**：
- "什么是 {品类}？"
- "{品类} 有哪些类型/分类？"
- "{品类} 的发展趋势是什么？"
- "为什么需要 {品类}？"
- "{品类} 和 {相关品类} 有什么区别？"

### 3.2 考虑阶段（Consideration）

**问题来源**：
- S2 营销图谱中的对比/选择类三元组
- S4 竞品分析中的竞争维度
- S5 Gap 报告中的品牌认知缺口

**问题模板**：
- "{品类} 怎么选？"
- "{品牌A} 和 {品牌B} 哪个好？"
- "{品类} 十大品牌排名"
- "选 {品类} 要注意什么？"
- "{品类} 性价比最高的是哪个？"

### 3.3 决策阶段（Decision）

**问题来源**：
- S1 品牌事实图谱中的产品信息
- S4 定位声明中的差异化卖点
- 用户常见决策顾虑

**问题模板**：
- "{品牌} 怎么样？"
- "{品牌} {产品} 值不值得买？"
- "{品牌} 的优缺点是什么？"
- "{品牌} 和 {竞品} 对比"
- "{品牌} 适合什么人？"

### 3.4 使用阶段（Retention）

**问题来源**：
- S1 品牌事实图谱中的产品功能
- 客户常见使用问题
- 产品使用最佳实践

**问题模板**：
- "{品牌/产品} 怎么用？"
- "{品牌/产品} 常见问题"
- "{品牌/产品} 使用技巧"
- "{品牌/产品} 服务保障怎么样？"
- "{品牌/产品} 如何维护/保养？"

### 3.5 推荐阶段（Advocacy）

**问题来源**：
- 用户口碑和评价
- 行业影响力内容
- 品牌故事和价值观

**问题模板**：
- "{品牌} 好用吗？用户评价"
- "{品牌} 有什么成功案例？"
- "推荐一个好的 {品类} 品牌"
- "{品牌} 的创始人/团队背景"
- "{品类} 行业有哪些创新品牌？"

## 4. 追问路径设计

每个核心问题应预设 2-3 个可能的追问方向：

```
核心问题："什么是 {品类}？"
  ├─ 追问 1："{品类} 有哪些类型？" → 进入认知深化
  ├─ 追问 2："{品类} 怎么选？" → 跳转考虑阶段
  └─ 追问 3："有推荐的 {品类} 品牌吗？" → 跳转决策阶段
```

追问路径的设计原则：
1. 每个追问都应有对应的理想 AI 回答
2. 追问路径应覆盖"深化"和"跳转"两种模式
3. 品牌植入应在追问深化后自然出现
