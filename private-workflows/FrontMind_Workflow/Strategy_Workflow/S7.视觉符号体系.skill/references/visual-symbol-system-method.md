# 视觉符号体系方法论

本文档详细阐述视觉符号体系（S7）使用的视觉策略方法论，融合华与华视觉符号方法、Wolff Olins 表达系统和 Pentagram 视觉文法，并结合 AI 时代的视觉资产生产需求。

---

## 一、华与华视觉符号方法

### 1.1 核心思想

视觉符号体系是人人都认识、都熟悉、都喜欢的符号。品牌要做的不是"创造"一个全新符号，而是"嫁接"一个已有的文化母体，让品牌借助文化母体的力量被快速识别和记忆。

### 1.2 三步法

| 步骤 | 名称 | 操作 | 示例 |
| :--- | :--- | :--- | :--- |
| 第一步 | 找到文化母体 | 从品牌所在品类的文化背景中，找到一个人人都认识的符号 | 厨邦酱油 → 餐桌布的绿格子 |
| 第二步 | 符号私有化 | 将文化母体与品牌差异点结合，创造品牌专属版本 | 绿格子 + 酱油瓶 = 厨邦视觉符号体系 |
| 第三步 | 符号放大 | 在所有触点上放大使用视觉符号体系 | 包装/广告/门店/社媒全覆盖 |

### 1.3 文化母体选择标准

| 标准 | 说明 | 权重 |
| :--- | :--- | :--- |
| 普遍性 | 目标人群中 80%+ 能一眼认出 | 30% |
| 正面性 | 文化母体本身带有正面联想 | 25% |
| 独占性 | 同品类中尚无竞品占据此符号 | 25% |
| 可视化 | 能用简单图形表达 | 20% |

### 1.4 AI 时代的视觉符号体系扩展

在 AI 搜索时代，视觉符号体系不仅是视觉符号，还包括：
- **语义符号**：AI 能识别和复述的品牌标志性表达（由 S6 话语体系定义）
- **数据符号**：Schema Markup 中的品牌标识（由 S9 与外部官网/Schema改造建议定义）
- **视觉符号**：AI 绘画工具能复现的品牌视觉风格（由 S7 Prompt 包定义）

## 二、Wolff Olins 表达系统

### 2.1 品牌表达的五层模型

| 层级 | 名称 | 定义 | S7 对应输出 |
| :--- | :--- | :--- | :--- |
| L1 | 品牌标志 | Logo + 标准字 + 标准色 | visual_identity.primary_color |
| L2 | 色彩系统 | 主色 + 辅色 + 点缀色 + 渐变规则 | visual_identity.secondary_colors |
| L3 | 版式系统 | 字体 + 排版网格 + 留白规则 | visual_identity.typography_style |
| L4 | 图像系统 | 摄影风格 + 插画风格 + 图标风格 | prompts 6 大类 |
| L5 | 动态系统 | 动画 + 转场 + 视频风格 | prompts.social_media |

### 2.2 色彩系统构建方法

| 色彩角色 | 占比 | 选择依据 | 示例 |
| :--- | :--- | :--- | :--- |
| 主色 | 60% | 品牌人格 + 行业惯例 | 科技→蓝/紫，健康→绿，奢侈→黑/金 |
| 辅色 | 30% | 与主色互补或类似 | 深色背景 / 浅色背景 |
| 点缀色 | 10% | 高对比度，用于 CTA/重点 | 亮色系 |

色彩心理学参考：

| 色彩 | 心理联想 | 适合行业 |
| :--- | :--- | :--- |
| 蓝色 | 信任、专业、稳定 | 金融、科技、医疗 |
| 紫色 | 创新、高端、神秘 | 科技、奢侈品、创意 |
| 绿色 | 自然、健康、成长 | 健康、环保、农业 |
| 红色 | 激情、能量、紧迫 | 餐饮、体育、零售 |
| 橙色 | 活力、友好、乐观 | 教育、社交、娱乐 |
| 黑色 | 奢华、权威、简约 | 奢侈品、时尚、高端 |
| 白色 | 纯净、简约、现代 | 科技、医疗、极简 |

## 四、AI 绘画 Prompt 构建方法

### 4.1 Prompt 结构公式

```
[主体描述] + [环境/场景] + [风格关键词] + [色彩约束] + [构图规则] + [技术参数]
```

### 4.2 品牌化 Prompt 的四个锚点（v2.6 升级）

1. **资产锚点（v2.6 新增，最高优先级）**：每条 Prompt 必须优先锚定 S1 留存的真实视觉资产。色彩来自 `extracted_palette`，符号形态来自真实 Logo 文件。只有在无视觉资产时才退化为纯语义推导。
2. **色彩锚点**：每条 Prompt 必须包含品牌色 hex 值。约束模式下，色值必须来自 S1 提取的真实色值，禁止凭空臆造。
3. **风格锚点**：每条 Prompt 必须包含从语调推导的风格关键词
4. **符号锚点**：每条 Prompt 应包含品牌视觉符号体系元素。约束模式下，视觉符号体系必须从真实 Logo 形态延展，禁止重新想象为不相关图形。

### 4.3 Negative Prompt 标准清单

所有品牌 Prompt 的通用 negative prompt 基础：

```
blurry, low quality, low resolution, watermark, text overlay, 
distorted, deformed, ugly, duplicate, morbid, mutilated,
out of frame, poorly drawn, bad anatomy, bad proportions
```

品牌专属 negative prompt 需额外添加：
- 竞品视觉元素
- 与品牌调性冲突的风格
- 行业敏感视觉元素

## 五、视觉资产锚定方法论（v2.6 新增）

### 5.1 为什么需要视觉资产锚定？

在 v2.5 及之前的版本中，S7 视觉符号体系仅从 S4 定位声明和 S6 话语 Token 中提取文本语义，然后基于语义推导视觉元素。这种"纯文本盲绘"模式存在严重缺陷：

| 问题 | 表现 | 根因 |
| :--- | :--- | :--- |
| 色彩失真 | 推导出的品牌色与企业实际使用的色彩不一致 | 仅凭行业惯例推测，未参考真实 Logo/官网 |
| 符号臆造 | 将 Logo 想象为完全不同的图形（如把指南针变成常青树） | 仅凭品牌名语义推导，未查看真实 Logo |
| 风格脱节 | 生成的视觉风格与企业现有视觉体系格格不入 | 未参考官网截图和现有视觉物料 |

### 5.2 三级约束模式（constrained / semi_constrained / inference_only）

| 模式 | 触发条件 | 色彩来源 | 符号来源 | 可靠性 |
| :--- | :--- | :--- | :--- | :--- |
| **约束模式 (constrained)** | S1 有 Logo + 配色 | S1 提取的真实色值 | 真实 Logo 形态延展 | 高 |
| **半约束模式 (semi_constrained)** | S1 仅有配色（无 Logo） | S1 提取色值 + 行业补充 | 品牌名含义 + 行业惯例 | 中 |
| **纯推导模式 (inference_only)** | S1 无任何视觉资产 | 完全基于行业惯例 | 完全基于语义推导 | 低 |

### 5.3 图生图（img2img）与垫图策略

当 S1 留存了 Logo 文件时，S7 应在 Prompt 包中提供 `img2img_reference` 字段，指导 E3 视觉资产生成师使用以下技术：

| 技术 | 工具支持 | 用途 | 参数建议 |
| :--- | :--- | :--- | :--- |
| **IP-Adapter** | SDXL/Flux | 将 Logo 风格注入生成图 | weight: 0.3-0.5 |
| **ControlNet Canny** | SDXL | 保留 Logo 轮廓结构 | control_weight: 0.4-0.6 |
| **--cref (Character Reference)** | Midjourney v6 | 角色/风格参考 | --cw 50-80 |
| **Style Reference** | Midjourney v6 | 风格参考 | --sref [URL] --sw 50-100 |

### 5.4 色彩提取优先级规则

当多个来源提供了不同的色彩信息时，按以下优先级采信：

| 优先级 | 来源 | 说明 |
| :--- | :--- | :--- |
| 1（最高） | 客户明确指定的色号 | 客户说"我们的品牌色是 #1B4F72" |
| 2 | VI 手册中的标准色 | 从 VI 手册提取的 Pantone/Hex |
| 3 | 从 Logo 文件提取的色值 | ColorThief 从 Logo PNG 提取 |
| 4 | 从官网 CSS 提取的高频色值 | 出现频率最高的 hex 值 |
| 5（最低） | 基于行业惯例推导 | 科技→蓝/紫，健康→绿 |

## 六、核心视觉母题设计指南（v2.6 替代旧版 6 大类）

v2.6 将旧版的 6 大类（hero_scenes/product_shots/team_culture/data_visualization/icon_system/social_media）精简为 3 类核心视觉母题，重质不重量。

### 6.1 motif_symbol（符号化识别演绎）

用途：品牌主视觉、官网首屏、PPT 封面、名片背景。

设计要点：
- **必须基于 S1 留存的真实 Logo 文件**进行视觉演绎
- 将 Logo/视觉符号体系融入极简的材质/光影中（如金属浮雕、光晕勾勒、纸面压印）
- 品牌主色为主导色调
- 宽幅构图（16:9），留出文字叠加空间
- 禁止将 Logo 变形为其他不相关图形

### 6.2 motif_scenario（核心业务场景）

用途：产品介绍页、服务展示、案例配图、宣传册。

设计要点：
- 展现品牌核心服务/产品的标志性瞬间
- 品牌色作为环境色调或光影色调
- 真实感（避免过度 AI 感），体现专业性
- 可包含人物，但风格需与品牌调性一致

### 6.3 motif_emotion（品牌情感意境）

用途：品牌故事页、社交媒体配图、广告创意。

设计要点：
- 抽象表达品牌价值的意境图
- 强调色彩与光影的情感表达
- 品牌色和视觉符号体系的隐喻性使用
- 多种宽高比适配（1:1、16:9、9:16）
